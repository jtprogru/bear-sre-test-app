# Security Policy

## Что это за репозиторий

Учебный HTTP-сервис для проверки инженерных навыков SRE. В продакшене не
используется и не предназначен для этого.

Ветки `task/*` содержат **намеренно неполные** реализации: отсутствующие
таймауты, утечку файловых дескрипторов, неполную обработку ошибок. Это учебные
задания, а не уязвимости. Ветка `main` — эталонная реализация, к ней и
относится всё написанное ниже.

## Поддерживаемые версии

Поддерживается только `main`.

## Как сообщить об уязвимости

Если нашли проблему в `main`, откройте private security advisory на вкладке
Security репозитория или напишите на <jtprogru@gmail.com>. Публичные issue для
уязвимостей, пожалуйста, не используйте.

Ответ в течение 7 дней.

## Что проверяется автоматически

На каждый push и pull request:

- `go vet`, `golangci-lint`;
- `govulncheck` — известные уязвимости в зависимостях и stdlib;
- `gosec` — статический анализ безопасности;
- `go test -race`;
- `hadolint` — линт Dockerfile.

Обновления зависимостей приезжают через Dependabot (gomod, docker,
github-actions) еженедельно.
